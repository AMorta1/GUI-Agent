## 统计口径

五类任务均至少进行过一次真实 GLM 测试，**真实任务覆盖 5/5，完整 E2E 成功 0/5**。
覆盖表示已经运行到真实结果或明确阻断，不表示执行过预期 GUI 动作。一个类别有多个经单独批准的历史尝试，不合并成成功样本。
只有真实动作、动作后感知、原验收通过、runtime completed、独立验收及退出码 0 才计完整成功。
mock 测试、离线证据回放、API 接通和无 API 桌面探针分别统计。

## 已验证能力与测试层级

- 接口/结构：GLM 截图请求、计划/动作结构解析已实测；本地 Qwen 单次静态 smoke 返回合法 needs_clarification，非 ready/E2E。
- 控制与局部反馈：阶段 2 控制功能验证通过；阶段 3 完成真实点击、重新感知和 CLICKED 独立反馈，后续 BUTTON OK 被 OCR 误识别，完整短闭环未通过。
- 菜单安全探针：一次真实点击后菜单保留、无额外焦点问题，API 0；受控 mock 停止不算任务成功。
- 人工拒绝探针：焦点弹窗一次，用户 No 后立即 blocked，无输入/后续模型调用，ASCII INPUT 未变；API 0。
- 浏览器预检：真实桌面截图/CPU OCR、唯一三行标签、每个真实 target_id grounding 只读校验通过；无点击、启动或 API。
- UIA 离线能力：保存证据支持明确 LabeledBy + OCR 点关联；地址栏/按钮的实际 FocusedElement 与输入框不同，拒绝。
- 方案 B 无 API 探针：一次真实 OCR-grounded 点击、早期和最后 write 入口焦点检查通过；测试替身强制拦截写入，real_write_calls=0；输入框和服务端仍空。

探针 `probe_passed=true` / 入口退出码 0 与 runtime 的预期 blocked 可以同时成立，表示安全链路探针通过，不表示搜索成功。

## 归因边界与后续清单

| 层级 | 有证据支持的问题/行为 | 留待 Week5，当前不实施 |
|---|---|---|
| 模型决策 | 文件重复点击；搜索/关闭未动作即 step_complete；非必要澄清 | 优化动作与完成声明时机，保持独立验证，不按任务硬编码 |
| Prompt 契约/反馈语义 | 模型选择不能证明结果的区域；浏览器 text_present 不能跨 OCR 元素拼接 | 通用说明反馈类型实际语义、步骤成功证据及完整名称限制；不用修正历史结果 |
| OCR | 浏览器三行识别正确，不是 OCR 能力失败；阶段 3 小字号 BUTTON OK 误识别确为 OCR 问题 | 单独研究可靠性，不降低阈值以迎合样本 |
| runtime 边界 | 步骤证据不通过、焦点变化、候选/旧坐标不合法时安全停止 | 单窗口不自动切到新浏览器/文件对话框；跨窗口能力单独设计，不为任务绕过 |
| 安全机制 | 授权弹窗可能关闭菜单/抢焦点；人工 Yes 不足以证明后续焦点 | 方案 B 仅局部受控模式；进一步评估输入时焦点 TOCTOU 和提交后文档变化 |

当前输入前最后检查与键盘发送仍非原子，输入过程中也可能失焦；STOP 不能撤销已开始操作。
禁止 Agent 外网导航不等于 Edge 零外联；没有 OS 级网络隔离保证。
Windows 主显示器以外的平台、多显示器及第二分辨率完整闭环未验证；公网搜索/真实 IM 未测试。
