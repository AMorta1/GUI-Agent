## 6. 失败案例

### F-01：整屏 OCR 产生目标假阳性

- 现象：首次 OCR 验证按 `7429` 搜索时，误匹配到背景编辑器中的源码 `if "7429"`；
- 原因：OCR 输入为整个桌面，测试窗口没有与背景应用隔离；
- 修复：根据 Qt 窗口逻辑坐标和 mss 物理分辨率裁剪测试窗口，随后只在窗口区域识别；
- 复测：英文目标和中文目标均在测试窗口内命中，边界框正确。

### F-02：集成目标文字过小

- 现象：50% 缩放时，按钮和输入框文字被识别为 `Lalget` 等错误内容，集成测试在执行动作前停止；
- 原因：按钮字体较小，输入框使用低对比度占位文字，缩小后不利于 OCR；
- 修复：改为高对比度大号 `CLICK` 和 `ASCII INPUT`，集成处理尺寸调整为原窗口的 75%；
- 复测：OCR 正确定位两个目标，点击和输入闭环通过。

### F-03：受限执行会话无法截图

受限执行环境无法访问真实桌面，切换到本机交互式桌面后验证通过。
